# ブンリの王子様

名古屋文理大学を舞台にした、約5分の恋と情報のノベルゲームです。
未成年向け・成年向けのモードを選んで、3つのミニ問題に挑戦します。

[ブラウザで遊ぶ](https://kouyadoufu-1214.github.io/bunri-prince/)

## 二つの物語

- **未成年向け（18歳未満向け）**：同級生の御家雄一と、隣の席から始まる恋。従来の小・中・高3コースを収録。大人の方も遊べます。
- **成年向け（18歳以上向け）**：22歳の大学4年生と教員・御家雄一の、言葉にできない恋。二進数・ANDとNOT・二分探索をヒントつきで学びます。紹介画面から「18歳以上・この物語をはじめる」を選んで開始します。

各モードに3種類の結末があります。クイズの正誤は恋愛の分岐に影響しません。
成年向けの年齢選択は自己申告です。生年月日の収集・保存は行いません。人物の設定や関係はすべてフィクションです。

## 未成年向けの3つのコース

| コース | 学べること |
| --- | --- |
| 小学生 | 0と1の合図、もし〜なら、順番に探す |
| 中学生 | 二進数、AND条件、線形探索 |
| 高校生 | 4桁の二進数、AND・NOT、二分探索 |

学年は難しさの目安です。大人も好きなコースを選べます。
全コースにヒントと解説があり、間違えても最後まで遊べます。
会話の選択によって3種類の結末に分かれます。クイズの得点は関係性に影響しません。

## 操作

- クリック、Enter、Space：会話を進める。表示中に押すと全文を表示。
- 1・2・3：選択肢を選ぶ。
- AUTO：会話の自動送り。問題と選択肢では止まります。
- ノート：学習内容を振り返る。ログ：会話を読み返す。
- タイトルへ戻る：次の来場者用に内容をリセット。

ログイン不要。プレイ内容は保存しません。音は初期状態でオフです。
遊ぶ時間は読む速度によります。

## ローカルで遊ぶ

このリポジトリをダウンロードして `index.html` をブラウザで開くと、オフラインでも遊べます。
Node.jsがある場合は `node serve.cjs` でプレビューを起動できます。

## 編集と検証

- `courses.js`：学年別の教材、問題、ヒント、小学生向け文章。
- `story.js`：未成年向けシナリオ、モードとエンディング分岐。
- `adult-story.js`：成年向けのシナリオと結末。
- `app.js`：ゲーム画面と操作。
- `style.css`：PC・スマホの表示。

`node --test story.test.cjs` で、未成年向け3コース＋成年向け1編・2,916通りの分岐と教材の整合性を確認できます。

## 作品について

登場人物の外見は提供された写真を参考に生成したイラストです。
人物の性格・台詞、物語、講義、教室は創作です。
大学の公式制作物であることを示すものではありません。

## エンディングの音楽

各エンディングに専用のオリジナルインスト曲を収録しています。

| モード | 結末 | 曲 |
| --- | --- | --- |
| 未成年 | 恋 | きみと、ひかりの中へ |
| 未成年 | 約束 | 窓際の約束 |
| 未成年 | 相棒 | ふたりの帰り道 |
| 成年 | 再会 | 名前で呼べる春 |
| 成年 | 余白 | 未送信の余白 |
| 成年 | 栞 | 恋を、栞にして |

音をオンにしていると、結末で専用曲へ自動で切り替わります。消音のまま到達した場合も、結末画面の「音楽を再生」から聴けます。タイトルへ戻ると専用曲は停止します。別タブへ移ると一時停止し、戻ると再開します。小・中・高の3コースでは未成年編の3曲が共通です。

`music.js` のモード・結末ごとの曲名とファイル指定を増やすことで、今後の結末追加にも対応できます。音源は `assets/ending-*.mp3` です。演奏は合成音によるオリジナル曲で、歌声はありません。

音声の停止・再開・切替・遅れて返る再生エラーの処理は `node --test music.test.cjs` で確認できます。
