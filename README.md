# ブンリの王子様

名古屋文理大学を舞台に、恋と情報の学びを楽しむブラウザーノベルゲームです。

**[ブラウザーで遊ぶ](https://kouyadoufu-1214.github.io/bunri-prince/)**

現在のバージョン：**4.2**。スマートフォン・パソコンに対応。インストール不要です。

- 未成年向けは中学生・高校生の2コース、全3編。同級生の雄一との物語。
- 成年向けは18歳以上、全3編。22歳の大学生と教員の物語。
- 1話7〜10分が目安。各編に3種類のエンディングと専用曲があります。
- 6枚の限定立ち絵、場面や選択による表情・距離の変化。
- ミニゲーム6種類。成年向けは複数の論理条件・通信コスト・統計の判断まで考える内容です。
- 心情・情景は背景の上に文章を重ね、セリフは名前付きの枠に表示します。

## 遊び方

「物語をはじめる」からモードと物語を選びます。物語一覧の「ミニゲームを試す」からゲームだけを体験することもできます。クリック、Enter、Spaceで文章が進み、選択肢はクリックまたは数字の1・2・3で選べます。ヒントやお手本を使っても恋の結末は変わりません。音は最初はオフで、スピーカーボタンから切り替えられます。

登場人物の設定・関係・台詞・講義・教室はフィクションです。

## 開発・動作確認

サーバー処理を必要としない静的サイトです。`index.html`を開くか、Node.jsのある環境で`node serve.cjs`を実行するとローカルで起動できます。

```sh
node --test story.test.cjs episodes.test.cjs staging.test.cjs passages.test.cjs music.test.cjs minigames.test.cjs
```

66件のテストで、物語分岐、読み順、音楽切替、ミニゲームの正誤・操作制約を検証しています。
