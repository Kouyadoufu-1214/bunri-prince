# ブンリの王子様

名古屋文理大学の架空の講義を舞台にした、文化祭向けの短編ブラウザノベルゲームの試作です。
「未成年向け」と「成年向け」の2モード、それぞれ3編、合計6編の短編集です。各編は約5分、情報のミニ問題3問、会話の選択による3つの結末があります。結末は合計18種類です。

[ブラウザで遊ぶ](https://kouyadoufu-1214.github.io/bunri-prince/)

## 追加した物語（2026-09-24）

元の講義編を残し、各モードに2編ずつ追加しました。どの物語からでも始められます。

| モード | 物語 | 内容・学び |
| --- | --- | --- |

未成年編は全3編とも、中学生・高校生の2コースで教材を変更します。成年編の主人公は22歳です。各編の最初の会話選択によって、途中の場面も3通りに変わります。

新しい12種類の結末に、それぞれ新しいオリジナルのインスト曲を追加しました。結末から「別の物語を読む」で同じモード・コースの次の一編を選べます。別の編を開始すると得点・ノート・会話ログはリセットされます。次の来場者へ交代する場合は「タイトルへ戻る」を使います。

## 遊び方

このフォルダの **index.html をブラウザで開くだけ**で遊べます。インストールもログインも不要です。
すべての画像・コードを同梱しているため、フォルダ一式をコピーすればネット接続なしでも動きます。

「物語をはじめる」でモードを選びます。

- **未成年向け（18歳未満向け）**：従来の同級生・御家雄一との物語。中学生・高校生の2コースを収録しています。学年は難しさの目安で、大人も遊べます。
- **成年向け（18歳以上向け）**：22歳の大学4年生と教員・御家雄一の、立場ゆえに伝えられない恋。紹介画面の「18歳以上・物語を選ぶ」から、講義・雨の日・最終発表の3編を選びます。年齢の自己申告であり、身分証の確認や生年月日の収集はありません。登場人物の設定・関係・台詞はフィクションです。

タイトルに戻るたびに、モード・得点・ノート・会話ログは初期状態に戻ります。モードや年齢確認の保存はありません。

ローカルプレビューを使う場合は、このフォルダで `node serve.cjs` を実行し、`http://127.0.0.1:8792` を開きます。

- クリック / Enter / Space：全文表示・会話を進める。
- 1・2・3：表示されている選択肢を選ぶ。
- AUTO：会話のみ自動送り。選択肢・クイズ・クイズ解説では止まります。
- ノート：解いたミニ問題の解説。ログ：ここまでの会話。
- 右上のスピーカー：オリジナルの簡単なBGMと操作音。初期状態は消音。
- 右上の全画面ボタン：対応ブラウザで全画面表示。
- 結末の「タイトルへ戻る」：物語・得点・ノート・会話ログをリセット。次の方はモードから選び直せます。

## 従来の講義編の内容

- 所要時間の設計目安：約4〜6分。読む速度によるため、実際の来場者層で測って文章量を調整してください。強制タイマーはありません。
- 中学生：3桁の二進数、AND条件、線形探索の比較回数を各1問。
- 高校生：4桁の二進数、ANDとNOTの組み合わせ、二分探索の比較回数を各1問。
- すべてのコースにヒントと正誤両方の解説があります。ノートとクリア画面も、そのコースの内容になります。
- 間違えても解説を読み、最後まで進めます。
- 会話の選択3回で結末が変化。クイズの得点は関係性に影響しません。
- 未成年向けの3つの結末：「君だけの、王子様。」「次の講義も、隣で。」「最高の相棒、発見。」
- 成年向けの3つの結末：「先生と呼ばない、春。」「まだ、送れない一行。」「恋を、栞にして。」
- 主人公の名前入力・性別設定・ユーザーデータ保存はありません。

大学名を舞台として使用しています。登場人物の見た目はユーザー提供写真を参考にしています。性格・台詞・物語・教室の絵・講義・受付の例は創作で、実在の人物の発言や実際の授業・施設の再現ではありません。
大学公式の制作物であることを示すものではありません。
舞台の参考：[名古屋文理大学 情報メディア学科 公式ページ](https://www.nagoya-bunri.ac.jp/department/media/)。

## 編集する場所

- `courses.js`：中学生・高校生の学習内容・導入会話・問題・ヒント・解説・ノート。
- `adult-story.js`：従来の成年向け講義編。教材は高校生コースから複製し、元データを変更しません。
- `episodes.js`：物語選択の一覧、新しい4編の会話・途中分岐・結末。
- `episode-lessons.js`：新しい4編の教材。未成年2編×2コース×3問＋成年2編×3問＝新規18問。
- `story.js`：共通シナリオ・登場人物名・結末とコース切り替え。選択肢のpointsの合計が4以上でSWEET、2〜3でNEXT CHAPTER、0〜1でBEST BUDDY。
- `style.css`：レイアウト、色、PC・スマホ対応。
- `app.js`：画面描画、文字送り、ノート・会話ログ、音。
- `assets/classroom-yuichi.png`：今回生成した背景兼キャラクターイラスト。
- `assets/PROMPT-yuichi.md`：御家雄一の画像の生成方法・最終プロンプト。

ルートにある既存ゲームとは独立しています。
