# ブンリの王子様

名古屋文理大学を舞台に、恋と情報の学びを楽しむブラウザーノベルゲームです。

**[ブラウザーで遊ぶ](https://kouyadoufu-1214.github.io/bunri-prince/)**

現在のバージョン：**5.0**。スマートフォン・パソコンに対応。インストール不要です。
未成年向け（中学生・高校生）3編、成年向け3編。各話3種類、計18種類のエンディングと専用曲があります。
1話10〜15分が目安です。読む速さと、パズルを考える時間によって変わります。

## 今回の更新

全6話に、近づいてから距離が戻る場面、最初に選んだ言葉を覚えている会話、最後の選択で変わる余韻を追加しました。ミニゲームで解説を読んだ場合、試行錯誤した場合、自力で解いた場合にも異なる反応があります。情景・心の声は背景へ直接表示し、セリフは名前付きの枠に表示します。

|物語|ミニゲーム|
|---|---|
|未成年・講義|隣のランプも変わるスイッチを、決まった手数で操作|
|未成年・ひみつ通信|複数の手掛かりから、重複のない暗号表を推理|
|未成年・展示復旧|状況メモを読み、不要な作業を除いて復旧手順を組む|
|成年・講義|切り替え途中も通信を守る、操作手順の設計|
|成年・雨の日|鍵・中継順・コスト・転送回数を両立する経路探索|
|成年・発表|集計対象を選別し、人数の重みも考えて数値を入力|

制限時間はありません。ヒント・お手本・誤答で恋の結末が不利になることはありません。未成年向けは3〜4個の記号や短い操作から始め、成年向けは複数条件を同時に考えます。

## 遊び方

「物語をはじめる」からモードと物語を選びます。「ミニゲームを試す」ならパズルから始められます。
クリック、Enter、Spaceで文章が進み、選択肢はクリックまたは数字の1・2・3で選べます。
音は最初はオフ。スピーカーボタンで切り替えられます。

登場人物の設定・関係・台詞・講義・教室はフィクションです。成年編の主人公は22歳。恋人としての続きは卒業し、評価・指導関係が終わってから描かれます。

## 開発・動作確認

静的サイトです。`index.html`を開くか、Node.jsのある環境で`node serve.cjs`を実行するとローカルで起動できます。

```sh
node --test story.test.cjs episodes.test.cjs staging.test.cjs passages.test.cjs music.test.cjs minigames.test.cjs tension.test.cjs
```

67件のテスト。物語分岐、読み順、音楽切替、暗号の解の一意性、回路の安全な最短手数、経路制約、集計の正誤・操作制約を検証しています。
